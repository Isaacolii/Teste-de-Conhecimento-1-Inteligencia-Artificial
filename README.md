# Teste de Conhecimento 1

Resolução do Teste de Conhecimento 1 da disciplina Inteligência Artificial — Unifap 2026.2.

O notebook usa a base histórica de crédito de uma fintech para treinar um modelo de regressão linear que estima o valor de empréstimo que pode ser oferecido a um novo cliente, a partir da idade, renda mensal, score de crédito e histórico de pagamentos.

## Arquivos

- `Teste_de_Conhecimento_1_IA.ipynb` — código, análise dos dados, gráficos, modelo, métricas, previsão e conclusão
- `base_credito.csv` — base de dados utilizada no notebook

## Como executar

Abra o notebook no Google Colab ou no Jupyter com o arquivo CSV na mesma pasta (no Colab, envie o CSV pela aba Arquivos) e execute todas as células. Bibliotecas: pandas, matplotlib e scikit-learn.
